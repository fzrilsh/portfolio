# Fazril Syaveral Hillaby — Portfolio

Personal portfolio website built with **Vite + React 19 + Tailwind CSS v4**.

## Stack

- **Build:** Vite
- **Frontend:** React 19, React Router DOM v7
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Optimization:** vite-plugin-image-optimizer

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Push to `main` → GitHub Actions builds the application and synchronizes `dist/` to the configured VPS with `rsync`.
